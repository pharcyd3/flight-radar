# Changelog

Every entry here corresponds to a `FIRMWARE_VERSION` in `src/config.h`. CI
publishes the section matching the compiled-in version as the changenotes
shown on the device's Firmware Update page (see [Building From
Source](development.md#cutting-a-release)) — bumping the version without
adding a matching section here fails the build on purpose.
